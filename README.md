---

DailyNova App — Feature List


---

1️⃣ Notes & Voice Notes

Add Notes: Type or use voice to add text notes.

Voice Input: Tap mic → speak → automatically saved as text.

Voice Output: Tap note → app reads it aloud.

Edit/Delete Notes: Update or remove old notes.

Search & Categories: Search by keyword; optional categories like “Study”, “Ideas”, “Random”.

Date/Time Tagging: Each note saved with timestamp.

UI Enhancement: Neon glow or pulse around mic when recording.



---

2️⃣ Tasks & Reminders

Add Tasks/Reminders: Voice or text input.

Voice Commands: “Remind me to call John at 5 PM.”

Voice Alerts: App speaks reminders at the scheduled time.

Edit/Delete Tasks: Update or remove tasks.

Mark Complete: Tap or say “Done” to complete a task.

Snooze Option: Delay reminder by set time.

Dashboard Integration: Next upcoming reminder shows on home screen.

Animation: Task cards glow when reminder is near.



---

3️⃣ Habit Tracker

Add Habits: Voice or text input (“Exercise 30 mins”, “Read 1 chapter”).

Daily Progress Check: Mark habits as done.

Streak Tracker: Shows streaks, percentage completion.

Voice Feedback: Encouragement messages (“Nice! You completed 3 of 5 habits today”).

Reminders for Habits: Optional scheduled notifications.

History & Summary: Weekly or monthly progress view with simple graphs.



---

4️⃣ Daily Journal

Create Entries: Type or dictate journal entries.

Voice Input: Speak thoughts → saved automatically.

Voice Output: Reads past entries aloud.

Date-based Navigation: Each day has its own page; navigate via calendar.

Edit/Delete Entries: Update or remove old entries.

Lock Option: Optional PIN/password for privacy.

UI Theme: Calm gradient backgrounds, soft fade-in animations while typing.



---

5️⃣ Motivation / Quotes

Random Quote of the Day: Shows motivational or inspirational quote each time the app opens.

Voice Output: Reads quote aloud.

Next / Repeat Quote: Tap or voice command to get another quote.

Favorite Quotes: Save quotes for later.

Share: Optional button to share quotes via social media or text.

Visuals: Glowing text animation, soft background color transitions.



---

6️⃣ Global Voice Commands (Optional)

“Add note” → opens Notes section, ready for dictation.

“New task” → opens Tasks/Reminders input.

“Track habit” → opens Habit Tracker.

“Write journal” → opens Journal for dictation.

“Inspire me” → opens Motivation section and reads quote.

“Exit” → closes app.


✅ All commands work offline, triggered via microphone.


---

7️⃣ Home / Dashboard

Summary Overview:

Number of notes saved today

Next upcoming task/reminder

Habits completed today / total habits


Quick Actions: Buttons for “Add Note”, “New Task”, “Add Habit”, “Journal”, “Quote”

Visuals: Neon-glow icons, smooth transitions between sections

Optional Daily Greeting: “Good morning! Here’s your quote and tasks for today.”



---

8️⃣ Additional Features / Polish

Offline Operation: No internet needed for core features.

Unified Storage: SQLite database storing Notes, Tasks, Habits, Journals, Quotes.

Neon / Glow Animations: Smooth transitions, glowing buttons/icons, pulsing mic when listening.

Settings Page:

Turn Voice Mode ON/OFF

Choose UI color theme

Manage quote list or add custom quotes

Backup / Export data locally
